# Konfiguracja systemu Windows

!!! info "Cel działu"
    Po tym dziale będziesz umieć skonfigurować interfejs sieciowy i podłączyć komputer do sieci, zdiagnozować i usunąć błąd połączenia, udostępnić internet innemu urządzeniu, dostosować ustawienia personalne według wskazań oraz zarządzać systemem za pomocą narzędzi administracyjnych.

!!! note "Nazwy w interfejsie"
    Pracujemy na Windows 10/11 w maszynie wirtualnej. Nazwy opcji podajemy po angielsku, a w nawiasie polski odpowiednik — np. **Device Manager (Menedżer urządzeń)**. Skróty `.msc` i `.cpl` działają tak samo w każdej wersji językowej.
