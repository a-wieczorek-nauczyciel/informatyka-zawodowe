# Konta i grupy lokalne

!!! info "Cel działu"
    Po tym dziale będziesz umieć tworzyć konta i grupy użytkowników według wskazań, zarządzać nimi w GUI i z wiersza poleceń, konfigurować profile użytkowników, nadawać prawa i przywileje oraz ustawiać przydziały dyskowe.

!!! note "Wersja systemu"
    Narzędzia `lusrmgr.msc`, `secpol.msc` i `gpedit.msc` są dostępne w Windows **Pro, Education i Enterprise**. W wersji Home ich nie ma — pracujemy na maszynie wirtualnej z wersją Pro lub Education.
