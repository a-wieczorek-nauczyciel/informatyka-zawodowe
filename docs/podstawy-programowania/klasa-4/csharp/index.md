# Programowanie obiektowe w C#

!!! info "Cel działu"
    Po tym dziale będziesz umieć modelować problem za pomocą klas i obiektów, projektować klasy z hermetyzacją i walidacją danych, budować hierarchie klas z dziedziczeniem, stosować polimorfizm przez metody wirtualne i klasy abstrakcyjne, definiować i implementować interfejsy oraz tworzyć i używać typów generycznych.

!!! note "Zanim zaczniesz"
    Zakładamy, że znasz podstawy C#: typy, instrukcje warunkowe, pętle, tablice, `List<T>` i metody. Jeśli coś wymaga przypomnienia, zajrzyj do części C# dla klasy 3. Każdą klasę zapisujemy w **osobnym pliku** o tej samej nazwie (`Gracz.cs` dla klasy `Gracz`), a program testowy — w `Program.cs`.
